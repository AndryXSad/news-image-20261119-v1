## Entry

`main.py` (Python 3.13, standard library only) copies the bundled `entry.png`
(1024×1024, 152,276 bytes) to the output directory given by
`MAKEFUN_OUTPUT_DIR`. No network, no randomness: two runs write identical
bytes.
