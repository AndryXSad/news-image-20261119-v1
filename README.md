## How it works

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` (1024×1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR/entry.png`
when that variable is set, and to the script's own directory otherwise.
No network, no randomness: two runs write identical bytes.
